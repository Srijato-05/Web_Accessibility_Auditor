# Web Accessibility Auditor (Backend Service)

High-fidelity web accessibility forensics engine built using FastAPI, SQLModel, and Playwright. Runs automated axe-core audits using visual, cognitive, motor, and neural forensics.

## Deployment Details
This Space runs the backend API in a Docker container on port `7860`.
